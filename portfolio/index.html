01六条规则

这些规则是从自己做坏的东西里总结出来的，后面每个项目都会回到这里。

  1. 缺数据，就写「未采集」。空着的格子比编出来的数字诚实。
  2. 动效只给正在发生的事。循环动画绑定运行状态；没有在跑的东西不动。
  3. 一个颜色只说一件事。强调色一旦承担两种意思，就不再是强调。
  4. 禁令写在最前面。交给模型的设计文档，先写不许做什么。
  5. 先有论点，才有画面。说不清这张图要证明什么，就先不画。
  6. 预览不是证明。截图好看不算数，要能指到数据来源或测试。

02agos · 本机 Agent 控制台

github.com/LeoLin990405/agos（公开）· 设计文档第一条：屏幕上不许出现数据证明不了的话。

为什么改：霓虹、发光边和四张大号指标卡是「AI 仪表盘」的默认皮肤，装饰在替数据说话，而数据是占位。

  • 初版交给另一个模型审查，退回硬编码颜色等问题；改版把指标卡阵列换成单条仪表带，辉光只留给运行中的任务，选中态不用侧边色条，去掉 emoji 导航和假的遥测标签。
  • 教训写回设计文档，并做成文案锁测试，防止下次又长回去。项目共 833 项测试、41 项浏览器回归。

03CivAgent · 用历史制度编排多个 Agent

开源项目分叉，100+ 次本人提交 · github.com/LeoLin990405/civagent · 系列文章见技术博客

把 57 种历史政体映射为 6 种多 Agent 编排模式：谁起草、谁审核、谁能否决，各对应一种工程取舍。系列文章逐一讲清每种制度换来了什么、付出了什么。

为什么改：讲的是「朝堂」，用的却是通用脚手架和英文标题，骨架和题材互不认识；没有探针的绿灯是会骗人的装饰。

仍未改：蓝紫玻璃底和暗色模板配色还在，下一步处理。

04Flickfic · 互动叙事平台

香港大学学生创业项目，由 REMi 发起；本人为主力工程师 · 2026.05 至今 · V1 已上线，V2 进行中

故事由文字、图像、视频、选择、互动等类型化片段组成，连续性由运行时串联，而不是塞进单个视频。生成分四层：大纲规划 → 片段编码 → 规则校验（不调模型，自动修正）→ 素材生成；创作者只审已通过校验的提案。

情绪曲线：用冯内古特的故事形状找出平淡段落

发布后按片段记录读者停留与流失，创作者可以定向重写低留存片段、发布新版本并比较前后留存；没人看过的片段显示「未采到」，不估算。

前后对照：暂缺。目前没有保存下来的「平淡版 → 重写版」真实片段，所以这里不放对比图。

05HackaCon 2026 · 合成一通从未发生过的电话

兰卡斯特大学 FACTOR 团队主办的全球对话合成黑客松 · 2026.09 · 由会话分析学者评审自然度

  • 用人类学方法分析英国人的日常对话，结合会话分析，判断合成对话的破绽多在节奏，而不在音色。
  • 据此迭代到工程：音色用克隆声音，节奏取自真人连读表演，逐词对齐。
  • 把话轮单独做成一层：插话切在具体的词上，加入附和与吸气，按网络延迟错开两端，结尾按电话收尾的典型顺序重写。话轮间隔中位数 0.56 秒，一端经 16 kbps 电话编码。

一次更正

早先判定声音相似度「已过线」，复查发现是两种度量口径不一致。公开更正，如实报告未过线：0.702（95% 区间 0.674–0.730），门槛 0.8302。

前后对照：暂缺。早期与最终混音的音频没有在本页公开，不放对比。

07口述访谈整理工具

Claude Skill · github.com/LeoLin990405/oral-interview-transcription-skill · 15★

与中科大科技史研究者共创：对方梳理口述史方法论文献（张藜、陈墨、Ritchie、Portelli 等），我负责工程。

原则是「存真」：方言、个性化措辞、前后矛盾和不确定的说法一律保留，只清除口语噪音；多角色分步整理，再做对抗式忠实度审计，逐段查漂移与越界。这和 01 的规则是同一件事：不替原始材料说它没说过的话。

08视觉评测草案（7 项）

把「好不好看」拆成可以复核的检查项。这是草案，字段与阈值还要在真实样本上校准。

检查项怎么判对应
状态完备空、加载、错误、长文本、窄屏五态逐一截图；缺一态记缺陷R6
数据诚实每个数字、每盏绿灯能否指到来源或探针；指不到即失败R1
动效语义循环动效是否只绑定运行态；减少动效设置下是否退为静态R2
色彩纪律强调色承担几种语义；超过一种记警告R3
碰撞与裁切文字与图形重叠、标签被裁、孤立标题，按实例计数—
题材一致模板骨架与题材语言是否冲突，能否一句话说清为什么用它R5
反套路清单渐变文字、玻璃拟态、侧边色条、泛用大号数字卡、无意义发光，出现即标注R4
